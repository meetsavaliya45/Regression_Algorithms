# Regression Algorithms Comparison — California Housing

A machine learning project comparing 10 regression algorithms on the California Housing dataset.

## 📌 Models Used

1. Simple Linear Regression
2. Multiple Linear Regression
3. Polynomial Regression
4. Ridge Regression
5. Lasso Regression
6. Elastic Net Regression
7. Decision Tree Regression
8. Random Forest Regression
9. Support Vector Regression (SVR)
10. Gradient Boosting Regression

## 📊 Evaluation Metrics

The models are evaluated using the following metrics:

1. MAE — Mean Absolute Error
2. MSE — Mean Squared Error
3. RMSE — Root Mean Squared Error
4. R² — Coefficient of Determination

All models use the same train-test split and common evaluation procedure for a fair comparison.

## 🗂️ Dataset

**California Housing Dataset**

1. Total observations — 20,640
2. Number of input features — 8
3. Target variable — `MedHouseVal`
4. Dataset format — CSV

### Features

1. `MedInc` — Median Income
2. `HouseAge` — Median House Age
3. `AveRooms` — Average Number of Rooms
4. `AveBedrms` — Average Number of Bedrooms
5. `Population` — Population
6. `AveOccup` — Average Occupancy
7. `Latitude` — Latitude
8. `Longitude` — Longitude

### Target

`MedHouseVal` — Median House Value

## 🎯 Objective

The main objectives of this project are:

1. Understand different regression techniques.
2. Implement multiple regression algorithms.
3. Train the models on the same dataset.
4. Evaluate their performance using standard metrics.
5. Visualize model predictions and performance.
6. Compare all models using a common evaluation framework.
7. Identify the best-performing model for the dataset.

This project demonstrates how different regression algorithms perform on the same dataset and how model selection can be based on quantitative evaluation metrics such as R², RMSE, MAE, and MSE.
