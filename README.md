Regression Algorithms Comparison — California Housing

A machine learning project comparing 10 regression algorithms on the California Housing dataset.

📌 Models Used
Simple Linear Regression
Multiple Linear Regression
Polynomial Regression
Ridge Regression
Lasso Regression
Elastic Net Regression
Decision Tree Regression
Random Forest Regression
Support Vector Regression (SVR)
Gradient Boosting Regression

📊 Evaluation
All models are evaluated using:
MAE — Mean Absolute Error
MSE — Mean Squared Error
RMSE — Root Mean Squared Error
R² — Coefficient of Determination
The project uses a common evaluation function and the same train-test split to ensure a fair comparison.

📈 Visualizations
The notebook includes:
Exploratory data analysis
Correlation matrix
Individual model prediction graphs
Decision Tree visualization
R² comparison
RMSE comparison
Master model comparison table

🗂️ Dataset
California Housing Dataset

20,640 observations
8 input features
Target: MedHouseVal

Python

🚀 How to Run
Download/clone this repository.
Open the .ipynb file in Google Colab.
Upload california_housing.csv.
Run the cells from top to bottom.
Check the final comparison table and graphs.

To understand, implement, visualize, and compare different regression techniques and determine which model performs best on the California Housing dataset.# Regression_Algorithms
